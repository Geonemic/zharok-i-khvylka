# Журнал прогресу

Короткий підсумок кожної сесії: що зроблено, де зупинилися, що далі. Новий запис — зверху.

## 28.10.2026 — сесія 3

**Рішення користувача:** ще 2 рівні в інших країнах з новими механіками й складніші, а потім одразу онлайн, щоб пробувати грати з друзями. Меню-планету скасовано: згодом зробимо розгалужене меню-мапу у власному стилі (записано в `docs/design.md`, розділ 2).

**Зроблено:**
- **Нові механіки в симуляції** (усе детерміноване, з тестами):
  - важелі;
  - ліфти;
  - противага;
  - приплив і відплив;
  - гондоли.
  
  Ворота й ліфти керуються плитами та важелями. Кожен механізм має свій колір зв'язку, тож видно, яка плита чи важіль чим керує.
- **Рівень `it-1` «Венеційські канали»** (тема Венеції в синю годину):
  - канал із припливом;
  - гондола, що піднімається разом із водою;
  - плита під водою;
  - сердечко можна дістати лише стрибком удвох із гондоли.
- **Рівень `fr-1` «Дахи Парижа»** (нічний Париж з Ейфелевою вежею, що мерехтить):
  - противага, щоб підняти партнера;
  - ліфти на важелях і плитах;
  - ворота з плитою й важелем перед дверима.
- **Тести, що рівні прохідні.** Кожен стрибок маршруту й кожна командна дія обох рівнів перевіряються автоматично (`packages/sim/test/mechanics.test.ts`).
- **Онлайн:**
  - rollback-неткод `packages/sim/src/rollback.ts` із тестами: двоє гравців із затримкою мережі бачать ту саму гру, що й без мережі;
  - сервер кімнат `apps/server` (Cloudflare Worker + Durable Object);
  - протокол `packages/protocol`;
  - екрани: вхід за ім'ям, кімната з кодом і посиланням-запрошенням, лобі (хто яким героєм, вибір рівня), чат у лобі й у грі (Enter), затримка в мс, «чекаємо на партнера», попередження про розсинхронізацію.
- **Перевірено в браузері:**
  - нові рівні малюються правильно;
  - лобі й чат працюють у двох вкладках;
  - два гравці через справжні з'єднання грають 60 кроків на секунду, без розсинхронізації.
  
  Для цієї перевірки використано тимчасову заглушку сервера, бо справжній локальний сервер Cloudflare не запускається на цьому ПК (див. нижче).
- `npm run dev` тепер запускає гру разом із сервером кімнат. Додано `npm run deploy`, у README — інструкцію з викладання на Cloudflare.

**Проблема на цьому (робочому) ПК:** локальний сервер Cloudflare (`workerd`) падає з «access violation». Причина — старий Microsoft Visual C++ Redistributable 14.28 (2020 рік). Лікування: користувач встановлює свіжий з https://aka.ms/vs/17/release/vc_redist.x64.exe. Гра працює й без цього, бракує лише локального онлайну. Для викладання на Cloudflare це не заважає.

**Гру викладено:** https://zharok-i-khvylka.geonm.workers.dev
- Акаунт Cloudflare користувача. Піддомен акаунта змінено з `paripan-pos` на `geonm`, тож інший сайт користувача тепер за адресою `paripan-pos.geonm.workers.dev`.
- Справжній сервер перевірено:
  - кімната, чат, вибір рівня, обмін героями, старт;
  - пересилання натискань і відбитків;
  - ping;
  - «кімната повна», «код зайнятий», вихід партнера.
- Оновлення гри: `npm run deploy` (на цьому ПК вже виконано вхід `wrangler login`).

Прототип меню-планети (`prototypes/planet`) видалено на прохання користувача: гальмував і не сподобався. Основа для подальшої роботи — сама гра.

**Де зупинилися:** можна пробувати грати з друзями за посиланням.

Далі:
- розгалужене меню рівнів («вишита мапа»);
- рівні `ua-2` і `ua-3`;
- редактор рівнів.

## 28.10.2026 — сесія 2

**Зроблено:**
- Погоджено маршрут: 11 країн по 3 рівні — Україна, Італія, Франція, Англія, Іспанія, Єгипет, Південна Африка, Антарктида, Австралія, Японія, Бразилія, плюс фінальний рівень удома. Записано в `docs/design.md`, розділ 2.
- Git встановлено на цьому ПК, але підключати GitHub користувач поки не хоче.
- Зроблено прототип меню-планети `prototypes/planet/index.html`:
  - мальована планета на WebGL2, яку можна крутити й наближати;
  - стрічка маршруту через 11 країн і фінал удома;
  - значки-пам'ятки країн;
  - хмари;
  - панель країни з трьома рівнями, зірками й станами рівнів;
  - демо-прогрес (Україна пройдена, Італія — поточна) і кнопка «Відкрити все»;
  - перемикач УКР/ENG.
  
  Кнопка «Грати» на першому рівні України відкриває прототип стилю.

- За відгуком переробили меню-планету:
  - маршрут тепер одне плавне коло на захід без перехрещень, тому порядок країн змінено (див. `docs/design.md`, розділ 2);
  - карта яскравіша: пляжі, річки, озера, дюни;
  - на поверхні стоять ліси, гори, кораблики, кити й великі пам'ятки країн.

- Відгук на планету: поки лишаємо, згодом переробимо мінімалістичніше й швидше (записано в дизайн-документі).
- Почали етап 1 і зробили фундамент:
  - монорепозиторій на TypeScript (npm workspaces, Vite, Vitest, React, Zod);
  - детермінована симуляція `@zh/sim` з 14 тестами (детермінізм і відкати, стихії, латаття, ворота, тримання за руки, фініш, оцінка);
  - формат рівнів `@zh/levels` і рівень `ua-1` «Карпатський ліс»;
  - рендер із темою «Купальська ніч» (графіка прототипу) і ліхтарі-чекпоінти;
  - головне меню з живими героями, вибір рівня, пауза (Esc), заново (R), меню підсумків із зірками;
  - найкращі результати зберігаються в браузері;
  - тексти українською й англійською.

**Де зупинилися:** фундамент етапу 1 готовий і перевірений у браузері. Далі — рівні 2 «Старий млин» і 3 «Плавні» з новими механіками (важелі, рухомі платформи, ящики тощо), потім етап 2 (редактор).
