# Жарок і Хвилька

Кооперативний платформер-головоломка для двох: вогонь і вода мандрують світом.

## Як запустити гру

Потрібен [Node.js](https://nodejs.org) 22 або новіший.

```bash
npm install
npm run dev
```

Потім відкрийте http://localhost:5173.

Команда запускає дві речі: саму гру й локальний сервер кімнат для онлайну. Онлайн можна пробувати у двох вкладках:
1. В одній вкладці створіть кімнату.
2. В іншій приєднайтеся за кодом.

Якщо на Windows сервер кімнат пише «access violation», встановіть свіжий [Microsoft Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe). Гра при цьому все одно працює, бракує лише онлайну.

**Керування:**
- Жарок: A D — рух, W — стрибок, S — взятися за руки;
- Хвилька: ← → — рух, ↑ — стрибок, ↓ — взятися за руки;
- Esc — пауза, R — заново.

Онлайн своїм героєм можна керувати і WASD, і стрілками. Enter відкриває чат.

## Як викласти гру в інтернет (Cloudflare, безкоштовно)

1. Зареєструйтеся на https://dash.cloudflare.com (безкоштовний план).
2. Один раз відкрийте розділ **Workers & Pages**, щоб Cloudflare створив вам адресу виду `ваше-ім'я.workers.dev`.
3. Увійдіть з комп'ютера. Відкриється браузер — натисніть «Allow»:

   ```bash
   npx wrangler login
   ```

4. Зберіть і викладіть гру:

   ```bash
   npm run deploy
   ```

   Наприкінці буде адреса `https://zharok-i-khvylka.<ваше-ім'я>.workers.dev`. Її й надсилайте друзям.

Після змін у грі повторюйте лише `npm run deploy`.
